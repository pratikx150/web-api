Vercel API

Email Avatar API

Use the endpoint below to get the real profile photo for any email address in JSON format.

https://your-project-name.vercel.app/api/avatar?email=hello@example.com

Example response:

{
  "success": true,
  "email": "hello@example.com",
  "avatar": "https://www.gravatar.com/avatar/....?s=512&d=mp&r=g",
  "avatar_url": "https://www.gravatar.com/avatar/....?s=512&d=mp&r=g",
  "pfp": "https://www.gravatar.com/avatar/....?s=512&d=mp&r=g",

}
